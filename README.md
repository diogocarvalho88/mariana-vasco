# Mariana & Vasco

Convite de casamento fictício, criado por brincadeira, em português de Portugal.

Site estático em `dist/`, sem dependências de build. O formulário é apenas uma demonstração: guarda a resposta no browser e não envia dados. Data, local e programa são inventados.

## GitHub Pages

Publicar a pasta `dist/` por GitHub Actions ou copiar o seu conteúdo para a raiz de uma branch dedicada a Pages.

## Desenvolvimento

Servir a pasta `dist/` com um servidor estático. As fontes Google são opcionais: existem fontes de sistema de reserva.
